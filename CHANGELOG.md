# Change log

## 1.0.0 — prepared release

First separate RASC scientific artifact. Incorporates the invariant-normalized
NLS checks (R1), the formal/discrete and conditional-theory controls (R2), and
the consolidated numerical evidence (R3). Publication preparation (R4) adds
explicit licensing, citation/deposit metadata, a complete manifest, portable
non-destructive reproduction commands and a manuscript-independent checker.

All retained archived inputs, results, snapshots, certificates and producer
sources are byte-identical to the R3 hand-off. No new PDE campaign is claimed
for R4. Packaging and documentation are not a new numerical dataset.

No remote commit, tag, release or DOI was created while preparing this package.

Final editorial check, 28 October 2026: the figure generator and its vector
outputs use uppercase A/B/C panel labels, matching the submitted manuscript.
Only panel lettering changed; recorded results, scientific producers, tables,
snapshots and solver certificates are unchanged. This unpublished preparation
keeps version 1.0.0; it does not move or overwrite a published tag.

Pre-release peer-review preparation, 29 October 2026: add the confirmed
Universidad de Málaga funding declaration (PPRO-B4-2026-004) to the public
metadata and documentation. Both reproduction drivers now run the already
included exact scalar/SG/stationary-NLS controls and the frozen kernel G1/H2
checks, through a new wrapper with explicit acceptance checks. No historical
producer, recorded input, numerical result or certificate was changed.
Add an independent SG initial-section control for theta0=0 and pi/2, with
symbolic rate verification and direct high-precision spatial quadrature.
This supports the manuscript clarification that the reported SG closed rate
selects theta0=0; it does not change any recorded PDE measurement.
